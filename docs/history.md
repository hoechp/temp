# History and attribution

[Documentation](README.md) · [Compatibility](compatibility.md)

Ultracomplex Math originated as Philipp Kolodziej's [Java project](https://github.com/hoechp/ultracomplexmath). The Python project preserves the full commutative complex/split-complex/dual algebra, its geometric motivation and author attribution. The owner selected the [0BSD license](../LICENSE).

The current documentation is organized by mathematical purpose and use case. The earlier migration records remain available in an immutable snapshot, rather than competing with current guidance:
