# Ultracomplex Math

A typed Python library for the eight-dimensional **commutative** real algebra
generated by

$$
i^2=-1,\qquad j^2=1,\qquad \varepsilon^2=0.
$$

This is a modernization of [Philipp Kolodziej's Java project](https://github.com/hoechp/ultracomplexmath).
The original basis and multiplication are retained. The numerical algorithms,
value model, expression parser and project tooling have been redesigned.

**Status: 0.1.0, an initial core migration.** Arithmetic, elementary functions,
formulas and square linear systems are implemented. The original geometry,
mechanism simulation, knowledge-discovery code and full GUI are **not** migrated.
See the [complete inventory](docs/inventory.md) and [migration guide](docs/migration.md).

## Quick start

Python 3.12 or newer. The core has **no runtime dependencies**.
Install from this checkout (no PyPI release has been published):

```sh
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows PowerShell instead:
# .venv\Scripts\Activate.ps1
python -m pip install -e .
```

```python
from ultracomplexmath import Ultra, I, J, EPS, ONE, evaluate

assert I * I == -ONE
assert J * J == ONE
assert EPS * EPS == Ultra()

x = Ultra(1, 1, 1, -1)  # 1 + j + i - i*j
assert x * x.inverse() == ONE
assert x.inverse() == Ultra(0.25, 0.25, -0.25, 0.25)

assert evaluate("exp(pi*i)").isclose(-ONE)
assert evaluate("sqrt(-1)") == I

# Dual numbers carry derivatives: f(2 + eps) = f(2) + eps*f'(2).
result = (2 + EPS).sin()
print(result.real, result.eps)  # sin(2), cos(2)
```

The coefficient order is exactly the Java order:
`(1, j, i, i*j, eps, eps*j, eps*i, eps*i*j)`.
Use keyword arguments to make intent clear: `Ultra(real=2, i=3, eps=1)`.
`Ultra.complex(2, 3)`, `Ultra.split(2, 3)` and `Ultra.dual(2, 3)` embed the
three original two-dimensional algebras into the common eight-dimensional type.

## Functions and formulas

`Ultra` supports `+ - * / **`, scalar operands, `inverse`, `exp`, `log`/`ln`,
`sqrt`, all six trigonometric and all six hyperbolic functions, and their inverse
functions. `log(base)` accepts an optional logarithm base. `abs(x)` returns the
Euclidean coefficient norm. `conjugate("i")`, `conjugate("j")` and
`conjugate("eps")` are independent generator conjugations.

```python
from ultracomplexmath import Formula, evaluate_system, solve

f = Formula("sin(x)^2 + cos(x)^2")  # parsed only once
assert f({"x": 2 + EPS}).isclose(ONE)

values = evaluate_system({"x": "t+1", "y": "x^2"}, {"t": 3})
assert values["y"] == Ultra(16)

assert solve([[0, 2], [1, 3]], [4, 7]) == (Ultra(1), Ultra(2))
```

Formula syntax uses explicit multiplication (`2*i`), function parentheses,
`^` or `**`, named variables and constants `pi`, `e`, `i`, `j`, `eps`.
`²`, `³`, `π`, `ε`, and the legacy unit symbols `î`, `Ê`, `ê` are accepted.
`log(x, base)` replaces the old infix logarithm syntax.
The evaluator walks a validated AST, never `eval` or `exec`. Attribute access,
indexing, arbitrary calls and Python statements are rejected. Missing variables
and cyclic formula dependencies raise `ExpressionError`.

```sh
python -m ultracomplexmath 'exp(pi*i)'
ultracomplex 'sqrt(-1) + j + eps' --json
```

## Mathematical behavior

This algebra has zero divisors: `(1+j)*(1-j)=0` and `eps*eps=0`.
Nonzero does **not** mean invertible. Division by such elements raises
`NonInvertibleError`; the implementation does not substitute a pseudoinverse.

The implementation uses two complex-dual channels:
`f(z + eps*w) = f(z) + eps*w*f'(z)`. This identity is exact where the local
analytic function exists; evaluation uses ordinary floating-point arithmetic.
There is no hand-truncated logarithm series or 127-factor inverse.

Principal functions use Python's `cmath` with a documented **positive-zero
cut convention**. Integers use repeated squaring; `0**0` is defined as one.
Square roots at zero with nonzero nilpotent part are rejected, while `sqrt(0)=0`.
Exact `==` is distinct from numerical `.isclose(...)`.

Read the [mathematical specification](docs/mathematics.md) for domains, branches,
the determinant definition and floating-point limitations.

## Development

```sh
python -m pip install -r requirements-dev.lock
python -m pip install --no-build-isolation -e .
python -m pytest
python -m ruff check .
python -m ruff format --check .
python -m mypy
python -m build --no-isolation
```

Alternatively, with `uv`: `uv sync --frozen --extra dev`, then prefix commands
with `uv run`. `uv.lock` includes optional plotting dependencies; they are only
installed when selected. The CI configuration runs on Python 3.12, 3.13 and 3.14.

Tests cover all 64 basis products, reproducible property-based algebra checks,
independent complex reference values and finite-difference derivatives, singular
cases, legacy regressions, parser rejection cases, and linear-system residuals.
To reproduce the Java observations without modifying its checkout:

```sh
python tools/legacy_probe.py ../legacy-ultracomplexmath
```

Selected legacy visual demonstrations have modern static equivalents:

```sh
python -m pip install -e '.[plot]'
python examples/plot_euler.py --output euler.png
python examples/plot_components.py --output components.png
```
