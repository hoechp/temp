What is being computed?

The ideal linear system obeys ż₁ = iωz₁ + iκz₂ and ż₂ = iκz₁ + iωz₂, starting at (z₁,z₂) = (1,0). The parameter substitution κ → κ + ε carries its derivative through the exponential. This is forward-mode automatic differentiation inside the algebra.

CoefficientsMeaningCurrent values

The independent reference is z₁ = eiωt cos(κt), z₂ = i eiωt sin(κt). The generator frequency is ω = 1.8. All displayed trajectories and derivatives are precomputed by Python's Ultra.exp(). This page only draws those samples; it contains no replacement ultracomplex implementation. Coupling is sampled in steps of 0.04; time in steps of 0.075. Stored coefficients are rounded to eight decimal places. No network access or third-party scripts are required.
